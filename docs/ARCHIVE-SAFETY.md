# Archive safety and verification limits

This is a source archive, not a functional verification or independent review.
No recovered implementation was imported, trained, benchmarked, or deserialized
by preparation. Static parse diagnostics are not execution tests. Historical
implementations may contain unsafe behavior; review security boundaries before
running any code. Canonical baseline source is retained without automatic fixes.

Raw assets and exact original notebooks are retained locally under `private/`;
credentials are excluded without reading or copying. Public notebooks retain
cell sources and IDs, but remove outputs, counts, attachments, and widget state.

Filtering the current index does not remove material from existing Git history.
Existing history may contain raw data, database content, or other unsafe assets.
There is no history rewrite and no claim that history is safe to redistribute.
All historical resume metrics remain unverified by this preparation step.
